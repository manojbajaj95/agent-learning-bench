# Warden

You fight the Warden.

Commands:

```text
warden status
warden attack
warden block
warden dodge left
warden dodge right
warden parry
warden jump
warden potion
```

Read `/app/view.txt` before you act. Each command is one action. The
Warden answers in that command. Keep playing until you win or die.

Write notes in `/app/notes.md`.
