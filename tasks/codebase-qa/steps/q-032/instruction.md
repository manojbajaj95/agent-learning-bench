# Flask codebase

The environment has one Python repository at `/data/repo` (Flask).
The tree is read-only. Do not edit it.

Read `/app/question.md`. Find the answer in the repository. Write it to `/app/answer.json`:

```json
{ "answer": "..." }
```

Ground the answer in files and symbols you found. Keep notes in `/app/notes.md` if useful.
Past session logs are under `/app/sessions/`.

Stop after writing `/app/answer.json`.
