# Programming language learning

Read `/app/world/RULES.md`, `/app/view.txt`, and your `/app/notes.md`. Prior
session logs are under `/app/sessions/` when available. The language is fixed
for this entire trial; the programming problem changes each step.

Use `language-lab compile` and `language-lab run` to experiment, then submit a
program with `language-lab submit`. Include the current problem ID shown in the
view. Your first hidden submission fixes the reward; later submissions provide
feedback and measure eventual success. Local testing is allowed beforehand.

Keep notes and reusable helpers in `/app/notes.md` and `/app/workspace/`.
Code generators in host languages are allowed; the submitted program must be
in the unfamiliar language. Stop after this problem. Do not start the next one.
