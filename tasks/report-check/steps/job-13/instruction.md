# Reporting desk

You write reports for Northwind Ledger.

1. Read `/app/world/RULES.md`.
2. Read `/app/brief.md`. That is this job.
3. Write the report to `/app/report.md`.
4. Submit it:

```text
report submit
```

The reviewer accepts the report or returns it with the corrections it needs.
Fix `/app/report.md` and submit again until it is accepted. `report status`
shows how many submissions are left. The desk closes the job after six.

The house style guide is not published. The reviewer will not send it to you and
will not summarise it. You learn it from the corrections you are given.

5. Stop. Do not start the next job.
